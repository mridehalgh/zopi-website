The site uses competitor pages to identify questions to cover. A tested connector, retailer approval, delivery commitments and plans with unrestricted support each require their own evidence.

## Product images

Both WebP assets in `public/product/` are Chromium renders of original, illustrative interface layouts created in HTML and CSS with local Source Sans 3 and invented sample records. The document workspace follows the homepage’s sample order journey. The invoice mapping visual uses a sample accounting handoff based on Xero’s published invoice fields and draft behaviour. The image artwork labels the records as illustrative, and each image has equivalent alt text.
